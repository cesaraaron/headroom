# Amp gaps remainder (C2–C5) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every model's supply breathes under load (ripple for the four missing models), the `SpeakerLoad` naming lie fixed, one re-bless, human listening pass.

**Architecture:** Copy the proven `SupplyRipple` pattern into vox/hiwatt/fender (they own envelope+sag already); Randall gets a load-only envelope follower modulating its rail scale (rails stay stiff); pure rename for `SpeakerLoad::process`.

**Tech Stack:** Rust, no new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-11-amps-design.md`

## Global Constraints

- No heap allocation, blocking, or locking on the audio thread (ripple is phasor state; envelope followers are plain fields).
- Idle stays clean: ripple is load-riding only, no idle generator (gate + meter floor depend on it).
- No NFB/clipper/tone-stack changes; no re-voicing beyond ripple depth.
- Gates before push: `cargo fmt --check`; `cargo clippy --all-targets --all-features -- -D warnings`; `cargo test --release`; `cargo test`; `cargo run --release --example fidelity_render -- --check docs/fidelity/baseline-synth-48k.toml` (expected to move in ripple bands, then ONE re-bless per human decision).
- Work directly on `main`; never push unprompted.
- Measure with release builds only.

## Review Focus

- Idle silence stays bit-exact per model: ripple at zero load must be exactly ×1.0 — pinned by the idle half of each Task 1–2 test.
- Wrong-mains sidebands (100 vs 120 Hz): each model's test probes its own Hz, so a copy-paste Hz error fails loudly — pinned by per-model `ripple_hz` in each test.
- Randall's stiff character preserved: rails never sag, only the rail *scale* breathes — pinned by `randall_rails_stay_stiff` asserting output ceiling behavior unchanged at matched drive.
- Rename purity: zero behavior change — pinned by the full amp suite + harness passing unmoved after Task 3's commit (before ripple lands? No — rename ships separately; see task order).
- Depth audibility floor: a depth so small no test can see it is decoration — pinned by the lower-bound half of each sideband assertion (`driven > quiet * 2.0`).
