# F1 limiter remainder Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** True-peak-aware lookahead limiting with an honest GR readout and an oversampled clamp, re-blessing the baseline for top-band movement only.

**Architecture:** Feed the existing envelope detector from a 4× detector stream, move the safety clamp into the 4× domain via the shared `Oversampler4::process` loop, publish block-minimum gain through a new `Levels::gr_db` relaxed atomic, and render it beside the `LIM` badge.

**Tech Stack:** Rust, no new dependencies (`crate::dsp::oversample::Oversampler4`).

**Spec:** `docs/superpowers/specs/2026-10-11-f1-limiter-design.md`

## Global Constraints

- No heap allocation, blocking, or locking on the audio thread; readout crosses as one relaxed `AtomicF32` store per callback.
- Detector ballistics, ceiling (−1 dBFS), and makeup (+1.5 dB) are untouched.
- Gates before push: `cargo fmt --check`; `cargo clippy --all-targets --all-features -- -D warnings`; `cargo test --release`; `cargo test`; `cargo run --release --example fidelity_render -- --check docs/fidelity/baseline-synth-48k.toml` (expected to move top bands only, then re-bless per CONTRIBUTING).
- Work directly on `main`; never push unprompted.
- Measure with release builds only.

## Review Focus

- Silence/DC into the limiter: GR readout must be exactly 0.0 dB, never NaN or negative — pinned by `gr_readout_is_zero_on_silence` in Task 4.
- Sustained hot square: the 4× clamp must hold the ceiling with `clamp_hits` counting per base-rate sample — pinned by `oversampled_clamp_holds_ceiling` in Task 2.
- Hard-panned peaks: one linked gain for both channels, readout identical regardless of pan — pinned by `gr_readout_matches_applied_gain` (driven both sides) in Task 4.
- Non-48 kHz rates: `latency()` (lookahead + oversampler delay) must scale with `sr` — pinned by `latency_scales_with_sample_rate` in Task 2.
- `reset()` while reduced: gain, envelope, and `block_min_gain` all reopen to 1.0 — pinned by `reset_reopens_gain_and_readout` in Task 4.

- [ ] **Step 3: Implement in `src/dsp/limiter.rs`**

Replace the base-rate safety clamp with the 4× loop over the gained delayed
signal (count one `clamp_hits` per base-rate sample where any high-rate phase
