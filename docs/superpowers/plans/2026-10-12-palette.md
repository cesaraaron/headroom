# Palette infrastructure + pedal rename Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Runtime theme infrastructure (single default theme) with `ui.conf` persistence, plus real product names on single-voice pedal tiles.

**Architecture:** `Theme` struct + `AtomicU8` index + `theme()` reader in `styles.rs` (mirroring `set_opaque`); flag-day rename of all color const uses; `PEDALS` stays `const` (liveries fixed) with renamed `name` fields; F-key or modifier-key cycle + conf write-back.

**Tech Stack:** Rust, ratatui TestBackend for color assertions, no new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-12-palette-design.md`

## Global Constraints

- Default theme values are value-for-value copies of the current `Rgb` triples: every existing UI snapshot passes UNMODIFIED (any default-snapshot diff is a bug).
- Gates: `cargo fmt --check`; `cargo clippy --all-targets --all-features -- -D warnings`; `cargo test --release`; `cargo test`. No fidelity involvement (UI-only).
- Work directly on `main`; never push unprompted.
- Render-thread only; no audio-thread contact.

## Review Focus

- A missed call site keeps the old color while everything else themes: the flag-day const deletion makes this a build error, not a runtime surprise — pinned structurally (delete consts in the same commit as the migration).
- Longer tile names overflow narrow terminals: "ELECTRIC MISTRESS" precedent (17 chars, same as "TREMOLO / VIBRATO") — pinned by `longest_pedal_name_fits_narrow_terminal` in Task 2.
- `ui.conf` missing/corrupt on first run: defaults to theme 0, no error surface — pinned by `theme_conf_missing_means_default` in Task 3.
- Out-of-range theme id in conf (forward-compat when theme #2 lands): clamps via `% THEMES.len()` — pinned by `theme_index_clamps` in Task 1.
- Pedal rename breaks preset/session name matching (names used as keys anywhere?): `PEDALS[].name` is display-only (verify by grep in Task 2 — if any logic matches on it, that is a finding, not a rename).
