# Fact-check review — Gilmour gear gap analysis (2026-11-02)

Status: **review only. No source code, no presets, and not the original research
doc were modified.** This file exists to be read next to
[`2026-11-02-gilmour-gap-analysis.md`](2026-11-02-gilmour-gap-analysis.md).

Scope: the gear claims in the "Gilmour's rigs by era" table, the Tier 1–3 lists,
the amp/cab notes, and the gear-specific chain-order experiments. DSP/code
claims (scoop depth, oversampling, effort estimates) are **out of scope** and
were not checked.

Method: primary check against the per-album/tour pages on Gilmourish (the doc's
own primary source), Kit Rae, Guitar.com's *Wall* survey, GroundGuitar's
Hiwatt/Alembic pages (Phil Taylor quotes), Reverb's Numb guide, and pedal-history
sources for release dates. No session sheets exist for any of this; where the
sources disagree the verdict is **contested**, and the suggested wording says so
rather than picking a winner.

Blunt summary: **the era table is roughly 60% right and the tier lists are worse
than that.** Three of the doc's headline "gaps" are real (rotary, Muff variants,
Tube Driver), but every one of them is described with the wrong era, the wrong
model, or the wrong circuit. The single biggest factual problem is that the doc
cites Gilmourish but does not follow Gilmourish's per-era pages — several rows
contradict the page cited in the same sentence.

## 2. What the doc missed

Ranked by how much it changes the product, not by how famous the gear is.

1. **Direct-to-console guitar tones (no amp, no cab).** The most consequential
   omission, because it makes several presets unachievable by construction.
   The *Shine On You Crazy Diamond* intro solo was "recorded
   straight into the mixing console, using only input compression to drive the
   signal and no amp. This is a technique David would repeat on songs like
   Another Brick in the Wall (part 2) and Coming Back to Life."
   <https://www.gilmourish.com/?page_id=17>
   → Should be stated in the doc (and in preset notes) as a hard limit: an
   amp+cab model cannot match those three parts; the closest thing is a
   compressor + EQ + console-ish saturation with the amp/cab bypassed.

2. **MXR Phase 100 (1976–79).** The actual Animals-era phaser. "He changed to a
   Phase 100 in 1976" — <http://www.kitrae.net/music/David_Gilmour_Effects_And_Gear.html>;
   Animals board lists "MXR Phase 100" — <https://www.gilmourish.com/?page_id=18>.
   → Add as a phaser voice *instead of* the Small Stone (which is 1980–81 only).

3. **Two rotary families, not one.** Leslie (horn/drum, woody tremolo) vs
   RA-200/Doppola/Maestro Rover (spinning speakers, chorus-like). The doc's DSP
   brief is a Leslie brief. <https://www.gilmourish.com/?page_id=4554>,
   <https://reverb.com/news/how-to-nail-gilmour-comfortably-numb-solo>
   → At minimum add a "family" switch; the chorus-like family is the one that
   unlocks Animals/Wall/Pulse.

4. **Maestro Rover.** DSOTM/WYWH-era rotary and the Division Bell **studio**
   rotary, distinct from both the Leslie and the RA-200.
   <https://www.gilmourish.com/?page_id=31> (session amps: "Maestro Rover
   rotating speaker … 6″ 35 W speaker"), <https://www.gilmourish.com/?page_id=16>.

5. **Mesa/Boogie Mark I (and Mark III).** Not Mark II C+. The Mark I was used
   *as an overdrive/preamp in the chain* — which is exactly the kind of stage
   the app lacks. <http://www.kitrae.net/music/David_Gilmour_Tone_SignalChainOrder.html>,
   <https://www.gilmourish.com/?page_id=22>. The Mark III Simul-Class is the
   1987–90 live version — <https://www.gilmourish.com/?page_id=2111>.

6. **Hiwatt SA212 50 W combo with Fane Crescendo.** A recurring Gilmour amp
   across three eras the doc already covers: MLOR studio
   (<https://www.gilmourish.com/?page_id=30>), Division Bell sessions
   (<https://www.gilmourish.com/?page_id=31>), OAI
   (<https://www.gilmourish.com/?page_id=32>), Rattle That Lock
   (<https://www.gilmourish.com/?page_id=6909>). ≈ one new cab + one amp model;
   more historically load-bearing than the G12-65 cab the doc proposes.

7. **Dynacord CLS-222 Leslie simulator (1994 rack).** Part of the PULSE rotary
   sound alongside the Doppolas — used on Any Colour / Brain Damage / Eclipse.
   <https://www.gilmourish.com/?page_id=2117>, <https://www.gilmourish.com/?page_id=2119>.
   → An argument for the rotary being a *pair* of voices (real rotor + rack sim),
   and a cheap win if only the rack sim is built.

8. **TC Electronic Booster+ (Line Driver/Distortion) + Sustain/Parametric EQ.**
   A core part of the 1987–90 distortion chain and far more present in that rig
   than the RAT the doc promotes. <https://www.gilmourish.com/?page_id=2111>.
   → Optional, but it is the honest answer to "what makes the MLOR solos sound
   like that", more than a RAT does.

9. **Talk Box (Heil) and E-Bow.** Two devices that *define* famous parts and
   appear nowhere in the doc: "Keep Talking" (talk box; also *Pigs*), and
   E-Bow on *Keep Talking* / *Take It Back* / *On a Island*.
   <https://www.gilmourish.com/?page_id=2117> (talk box on the PULSE board),
   <https://www.gilmourish.com/?page_id=31> (E-Bow), <https://www.gilmourish.com/?page_id=18>
   (talk box, Pigs sessions). → Cannot be modelled without a mic (talk box) or a
   sustainer (E-Bow); say so explicitly instead of silently omitting them.

10. **Sound-on-sound belongs above the Tier-3 fuzz pedals.** It is documented,
    it is how Gilmour plays *Shine On* live from 2001 on, and it is a delay
    feature, not a new pedal: volume pedal + 1500 ms delay with ~20 s of
    repeats into a separate amp. <https://www.gilmourish.com/?page_id=156>,
    <https://www.gilmourish.com/?page_id=218>. → Re-rank, don't defer.

11. **The studio *Sorrow* intro is not a Muff.** Gilmour's own account: HM-2 +
    Boss DD into a Fender Super Champ, blended with the GK 250ML's internal
    distortion. <https://www.gilmourish.com/?page_id=3389> (comment quoting
    Guitar World 1988). → Worth one line so the "Sorrow = Civil War Muff"
    preset is labelled as the live arrangement.

### Gear the doc could add but probably shouldn't

These are real and documented, but they are era trivia or duplicates of things
the app already approximates — listed so a future reader doesn't "discover" them
and re-open the question:

- Boss MZ-2 Digital Metalizer — on the 1994 board
  (<https://www.gilmourish.com/?page_id=2117>); no song is documented.
- Gallien-Krueger 250ML / Fender Super Champ — the studio *Sorrow* chain; solid
  state and a small combo, low modelling value.
- Alembic F-2B as a *pedal* — the doc's option (b); it is a rack preamp, and the
  amp-model option is the honest one.
- Roland BF-1 / AP-7 Jet Phaser — spotted at Olympic 1993, no song
  (<https://www.gilmourish.com/?page_id=31>). The doc already says skip; keep it
  that way.
- Univox Super Fuzz — same status: spotted in the 1993 session footage, no
  recording evidence. Keep only as a footnote.
- Boss SD-1 / CE-3 / MXR Pitch Transposer — 1984 board furniture, nothing
  distinctive enough to model.
- Ibanez CP-9 as a third compressor *voice* — one intro (Time, 1994). Fold into
  the existing "transistor" voice.

## 3. What to drop

Blunt list, highest-confidence first.

1. **Mesa/Boogie Mark II C+.** Gilmour is not documented using one anywhere. It
   is Mark I (Wall live, About Face) and Mark III (1987–90 live). The IIC+ claim
   traces to UberProAudio's generic "reportedly used" list, which is the weakest
   source in the doc's own bibliography. Delete, don't rename.
2. **Marshall 4×12 with G12-65s.** Unsupported; documented Marshall cabs are
   G12M, and the G12-65 was only a Marshall OEM speaker c. 1979–83 — it cannot
   be the Division Bell cab. Also low value: the Greenback cab already covers it.
3. **EHX Small Stone as the 1976–79 phaser.** It is the 1980–81 live pedal.
   Replace with Phase 100.
4. **CE-2 from the 2016 row.** Not in the rig, not in any 2016 patch.
5. **Rotary from Pompeii 2016.** Not in the rig, not in any 2016 patch.
6. **"Tube Driver, the defining lead pedal of 1987–2016."** The 1987–90 rig has
   no Tube Driver at all. It is 1993–2016.
7. **"Alembic from 1979."** Two roles, two dates: RA-200 preamp (early 70s),
   Hiwatt front end (late 80s–early 2000s).
8. **"P-1/P-2 are Ram's Head clones."** True for P-1, false for P-2.
9. **"RAT II" as the pre-1988 RAT.** RAT2 is 1988.
10. **"Power Boost is a germanium overdrive."** It is silicon. This one matters
    because it is the stated justification for the Tier-2 drive mode.
11. **"Fender Showman" for 1984–87.** It is a Twin Reverb II.
12. **"Marshall" in the 1987–90 row.** WEM + Hiwatt SE-4123 only.
13. **The claim that the tweed Twin is "early-Floyd trivia."** The doc's own
    2001–02 row depends on it.
14. **"Hiwatt, WEM" for Meltdown 2001–02.** That run was acoustic, on tweed
    combos.
15. **Roland BF-1 / AP-7 as a Tier-3 line item.** Session trivia, no song, and
    the doc already says skip — delete the row rather than carry it.

## 5. Source-quality notes

- **Gilmourish is cited but not actually used.** Several rows contradict the page
  cited for them in the same line (Meltdown amps, 1987–90 Marshall cabs, 2016
  CE-2, P-2-as-Ram's-Head). The fix is mechanical: re-derive each row from
  `?page_id=16/17/18/20/22/30/2111/31/2117/156/32/218/7538`.
- **UberProAudio is the weakest source in the list** and is the origin of the
  Mark II C+ error (its page is a "reportedly used" gear dump that also lists an
  SS-3 and a Roland RE-201). Demote it below Kit Rae and stop using it for model
  numbers. <https://www.uberproaudio.com/who-plays-what/160-pink-floyd-david-gilmours-guitar-gear-rig-and-equipment>
- **Reverb's Numb guide is good on the RA-200 and bad on the delay.** It says
  Gilmour used a TC 2290 on *The Wall*; the 2290 was released in 1986. Use it for
  the rotary/preamp description, not for the delay unit.
  <https://reverb.com/news/how-to-nail-gilmour-comfortably-numb-solo>
- **Tone From Heaven was unreachable at review time** (transport error on both
  http and https). The doc cites it as a source for Cornish board history; that
  claim could not be verified here. Either re-check before publishing or drop the
  citation. <https://tonefromheaven.com/HistoryPCDG.html>
- **Pedal release dates matter and are checkable.** Two of the doc's errors
  (RAT2 in 1984, 2290 on a 1979 record) fall out of release dates alone, with no
  Gilmour-specific source needed.
